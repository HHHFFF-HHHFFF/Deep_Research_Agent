# 离线测试说明

当前测试覆盖：

1. Qwen／DeepSeek 场景配置继承、环境变量加载、路由、降级与序列化
2. 研究请求、统一运行入口、阶段回调、取消和错误脱敏
3. Markdown／TXT／PDF／DOCX 真实解析、缓存、内容哈希去重、虚拟 Embedding 和 FAISS 检索
4. FastAPI 请求校验、统一错误、OpenAPI 文档和报告下载
5. SQLite 任务持久化、单任务互斥、启动恢复和关闭中断
6. 文件上传路径、扩展名、文件签名、解析结果、单文件、总量和文字长度限制
7. React 主题校验、模型选择、资料上传和任务创建
8. 前端状态轮询、终态停止、连续失败暂停、StrictMode 和任务编号恢复
9. 任务取消、最近任务、RAG 状态、资料文件名、安全 Markdown 报告预览与下载
10. 前端业务错误、网络中断和服务未启动提示
11. FastAPI 生产静态托管与 API 同源访问

运行全部测试：

```bash
python -m pytest -q -p no:cacheprovider
```

默认测试必须完全离线，不读取真实模型密钥，也不访问模型或网页服务。真实 API 只用于用户明确发起的人工验收。

运行前端测试：

```bash
cd frontend
pnpm test
```

前端测试使用模拟 `fetch`，不会启动后端，也不会上传真实资料。

完整质量门禁见根目录 README 的“离线质量检查”。
