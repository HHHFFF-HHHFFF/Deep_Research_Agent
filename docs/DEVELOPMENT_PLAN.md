- 本轮完成：文档解析、切分、去重、Qwen Embedding、会话级 FAISS、Top-K 检索和本地证据注入

## 二、路线调整决定

原 P1-1 至 P1-5 以及后续 FastAPI、Next.js、数据库和任务队列计划全部终止。

继续保留：

- P1-M1：全仓 Ruff 告警清理和代码规范基线
- P1-M2a 至 P1-M2d：已完成的基础类型、组件数据、序列化和模型适配修复
- P1-M2 尚未处理的 463 个历史类型问题：暂停，不阻塞界面开发
- P1 之前完成的动态研究主题和 Qwen／DeepSeek 模型路由

不再保留：

- 统一任务状态枚举和进度事件模型
- `ResearchResult` 与 `ResearchService`
- 应用容器和统一资源生命周期重构
- 离线任务状态机端到端测试
- FastAPI、Next.js、PostgreSQL、Redis、pgvector 和后台队列

## 三、最终产品边界

最终交付一个本地运行的单页 Streamlit 应用：用户输入研究主题，选择 Qwen 或 DeepSeek，系统调用现有工具型 Agent 完成网页研究，并在页面展示和下载 Markdown 报告。

本地文档 RAG 后端已经完成；Streamlit 只需补充可选上传控件和安全落盘，不再增加其他业务模块。

## 四、开发步骤

### S0：轻量化复位

状态：已完成

- 撤销未提交的 P1-3 至 P1-5 改动
- 删除 P1-1 的结果、状态和事件模型
- 删除 P1-2 的 `ResearchService`、运行时协议和对应测试
- 重写项目范围、技术需求、开发计划和 README
- 保留 P1-M1、P1-M2 与现有研究主体

验收标准：项目中不再出现平台化路线或 `ResearchService` 依赖，现有离线测试继续通过。

### S1：实现本地文档 RAG

状态：已完成

- 使用 `mdify` 将本地文件转换为 Markdown
- 默认按 1000 字、150 字重叠切分文档
- 使用内容哈希生成稳定片段 ID，重复文档不重复索引
- 通过独立 Embedding 路由生成向量并写入会话级 FAISS
- 使用研究主题检索 Top-K 4 个相关片段
- 将来源、片段编号和相似度连同证据注入现有 Agent
- 对文档中的标签进行转义，并标记为不可信证据
- 命令行支持重复传入 `--file`

验收结果：7 个 RAG 离线测试通过，其中包含真实 FAISS 与虚拟 Embedding 集成测试。

### S2：提取轻量研究调用函数

状态：下一步

目标：不重构现有 Agent，只把命令行中的重复初始化和调用整理成一个可复用异步函数。

预计改动：

- 新增一个轻量研究调用模块
- 输入仅包含研究主题、文件列表和模型覆盖项
- 返回最终报告文本；失败时抛出或转换为简短错误
- 命令行入口改为调用该函数

明确不做：状态机、事件总线、任务编号、持久化和复杂依赖注入。

验收标准：原命令行用法不变，输入主题后仍能运行一次研究；轻量调用函数可被离线测试替身验证。

### S3：实现单页 Streamlit

## 五、强制范围控制

后续每个需求开始前必须检查：

1. 是否直接服务于“输入主题并生成研究报告”。
2. 是否可以复用现有 Agent、工具或 FAISS。
3. 是否会引入数据库、服务端 API、队列、多用户或分布式组件。
4. 是否能用一个页面和一个轻量调用模块完成。

若第 3 项为“是”，默认拒绝该需求；若新增超过两个主要源码文件，必须先重新评估范围。

## 六、每步工作流程

每次开发前：

1. 阅读本文档的当前指针。
2. 检查 Git 工作区和上一步验收结果。
3. 向用户说明当前进度和本次唯一目标。

每次开发后：

1. 运行相关离线测试和 Ruff。
2. 更新本文档中的状态、验证结果和下一步。
3. 每完成一步提交并推送一次；除非用户明确要求合并多个步骤。

## 七、面试解释口径

> 这是一个本地单用户的深度研究助手。用户输入研究主题并选择 Qwen 或 DeepSeek 后，工具型 Agent 会调用网页搜索、内容分析和报告工具，最后在 Streamlit 中展示 Markdown 报告。项目已实现基于独立 Embedding 和 FAISS 的本地文档 RAG。为了保证个人项目可掌握，我主动放弃了前后端分离、数据库、任务队列和多租户，只聚焦模型路由、Agent 工具调用、研究流程和轻量交互闭环。

面试中重点解释：

- Agent 如何选择和调用研究工具
- Qwen 与 DeepSeek 如何通过统一兼容接口切换和降级
- 为什么聊天模型与 Embedding 独立配置
- FAISS 与曾使用的 ChromaDB 检索器在职责上的对应关系
- Streamlit 如何调用异步研究函数
- 为什么主动控制范围而不做平台化
