# 项目范围

## 一、产品定位

本项目是一个本地运行的个人深度研究助手，也是用于展示 Agent、模型路由、网页研究和本地 RAG 能力的简历项目。

用户输入一个研究主题后，系统调用现有工具型智能体完成资料搜索、内容分析和中文报告生成。界面采用单页 Streamlit，只服务单个本地用户，不建设通用平台。

## 二、核心使用流程

1. 用户在 Streamlit 页面输入研究主题。
2. 用户选择 Qwen 或 DeepSeek 作为聊天模型。
3. 用户可选上传本地文档，文件路径交给现有研究主链路。
4. 系统同步运行一次研究任务。
5. 页面展示最终 Markdown 报告，并允许下载。

## 三、保留的主体能力

- 工具调用型 Agent 及其现有执行循环
- Qwen、DeepSeek 聊天模型切换与备用模型降级
- 独立 Embedding 配置
- 网页搜索、抓取、分析和报告工具
- FAISS 本地向量检索与文件系统环境
- AsyncIO 异步调用
- Pydantic 研究输入校验
- Ruff、mypy 和 pytest 质量检查

这些能力是项目主体，本轮轻量化不重写其内部架构。

## 四、轻量 Streamlit 界面

首版界面只包含：

- 研究主题输入框
- Qwen／DeepSeek 模型选择
- 可选备用模型设置
- 开始研究按钮
- 运行中提示
- Markdown 报告展示与下载

本地文档上传在基础界面稳定后接入，直接复用已有 `files` 参数和 FAISS，不再引入新的向量数据库。

## 五、明确排除

以下能力不进入本项目：

- FastAPI 与 Next.js 前后端分离
- PostgreSQL、Redis、任务队列和后台工作进程
- 用户注册、登录、权限、租户和多人协作
- 任务历史、数据库持久化和跨设备同步
- SSE、WebSocket 和复杂实时进度系统
- 微服务、Kubernetes 和云原生平台化改造
- 多智能体辩论、量化交易和移动设备自动化
- 新建另一套 RAG 框架或接入多个向量数据库

## 六、规模约束

- 界面保持单页，不增加路由和管理后台。
- 新增界面层原则上只包含 `streamlit_app.py` 和一个轻量研究调用模块。
- 单次会话只运行一个研究任务。
- 运行结果只保存在当前页面会话和生成的本地报告文件中。
- 只有现有主体功能无法完成页面调用时，才允许小范围调整核心代码。
