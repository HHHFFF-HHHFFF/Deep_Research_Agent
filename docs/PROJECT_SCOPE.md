# 项目范围

## 产品定位

深度研究智能体是一个安全、可观测、可评测的研究助手。它接收研究问题和可选文档，规划研究过程，收集并验证证据，最终生成带来源引用的报告。

对用户可见的产品是研究助手，工程重点则是其底层可复用的智能体运行时。

## 核心流程

1. 接收研究任务和可选本地文档。
2. 扫描不可信输入中的提示注入特征。
3. 创建并持续更新研究计划。
4. 搜索、抓取、解析和分析资料来源。
5. 交叉核验证据并保存引用来源链路。
6. 生成结构化研究报告。
7. 记录模型调用、工具调用、延迟、词元、成本、失败和安全事件。

## 保留能力

- 工具调用型智能体运行时
- 模型提供方抽象
- 提示词与结构化消息处理
- 研究、文档分析和报告工具
- 记忆、执行轨迹和组件版本记录
- 文件系统与本地向量检索环境
- 可扩展的技能与工具契约

## 明确排除

- 量化交易与市场数据采集
- 移动设备自动化
- 多智能体辩论演示
- LeetCode 与学术基准运行器
- 内嵌的浏览器、LightRAG 和 TextGrad 源码
- 不受限制的命令行或进程内动态代码执行
- 在没有可复现实验数据时宣称自主进化

## 下一阶段边界

保留代码是过渡基线，不是最终架构。下一阶段将使用统一资源生命周期组件替代重复的上下文管理器，并消除导入阶段的全局初始化。
