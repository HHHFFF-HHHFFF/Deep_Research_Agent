# 项目范围

## 一、产品定位

本项目是一个本地运行的个人深度研究助手，完整覆盖 Agent、模型路由、网页研究、本地 RAG 和稳定 Web 交互能力。

用户输入研究主题并可选上传本地资料后，系统调用工具型 Agent 完成网页搜索、内容分析和中文报告生成。项目服务单个本地用户，目标是可靠地完成一次研究闭环，而不是建设通用 AI 平台。

## 二、核心使用流程

1. 用户在 React 页面输入研究主题。
2. 用户选择 Qwen 或 DeepSeek 作为聊天模型。
3. 用户可选上传本地文档。
4. FastAPI 创建待确认任务并给出默认研究计划，用户可以修改步骤。
5. 用户确认计划后才启动 Agent，前端通过普通 HTTP 轮询真实阶段和安全执行活动。
6. 后端复用现有 Agent，并把本地文档交给已完成的 FAISS RAG。
7. 页面展示成功、失败、取消或中断状态。
8. 系统汇总网页与本地 RAG 证据，核验报告引用是否匹配本次真实来源。
9. 用户查看来源、核验状态并下载报告，刷新后仍可打开最近任务的完整结果。

## 三、保留的主体能力

- 工具调用型 Agent 及其现有执行循环
- Qwen、DeepSeek 聊天模型切换与备用模型降级
- 聊天模型与 Embedding 模型独立配置
- 网页搜索、抓取、分析和报告工具
- 文档切分、内容哈希去重、独立 Embedding 和 FAISS Top-K 本地检索
- 对网页和本地文档进行不可信内容隔离
- AsyncIO 异步调用
- Pydantic 输入与 API 数据校验
- 固定 RAG 标注集、Recall@K／MRR 和 Agent 安全快照回归评测
- Ruff、mypy 和 pytest 质量检查

Web 层只负责把这些能力稳定地提供给用户，不重写研究核心。

## 四、稳定 Web 界面范围

首版界面保持单页，包含：

- 研究主题输入
- Qwen／DeepSeek 模型选择
- 可选本地文档上传
- 任务创建与重复提交保护
- 执行前默认研究计划、逐行编辑与显式确认
- 待确认计划持久化、跨重启恢复与直接取消
- 当前研究阶段、运行时间和错误提示
- Agent 规划、资料检索与工具调用的安全执行时间线
- 活动状态、轮次、工具名称和耗时的刷新恢复
- 网页来源与本地 RAG 片段组成的统一证据面板
- 引用有效数量、证据覆盖率、未匹配引用警告和来源跳转
- 任务取消
- Markdown 报告安全展示与下载
- 有限数量的最近任务与刷新恢复

后端提供最小 FastAPI 接口，使用 SQLite 保存任务、确认计划、文件、报告、安全活动、证据和引用核验元数据。研究任务仍在单个应用进程内运行，同一时间只执行一个任务；待确认任务不占用运行槽。活动记录不保存模型隐藏的逐字推理、工具参数或原始输出；引用核验只做引用目标与本次来源集合的一致性检查，不做语义事实判定。

## 五、本地 RAG 边界

- 继续使用现有 `mdify` 文档解析流程。
- 通过 mdify 底层 MarkItDown 的受限入口校验真实格式并缓存解析结果，不引入第二套文档框架。
- Web 限制为单文件 10 MB、最多 5 个、总量 25 MB，解析后每个文件最多 20 万个字符。
- 继续使用默认 1000 字、150 字重叠的切分策略。
- 继续使用内容哈希去重、独立 Embedding、FAISS 索引和 Top-K 4 检索。
- FAISS 保存向量索引，SQLite 只保存业务元数据，二者不互相替代。
- Web 阶段只增加上传限制、安全落盘和任务关联，不另建 RAG 框架。

## 六、明确排除

以下能力不进入首版：

- 用户注册、登录、权限、多租户和多人协作
- PostgreSQL、Redis、Celery、RabbitMQ 和独立工作进程
- SSE、WebSocket 和复杂实时进度系统
- Next.js、服务端渲染、多页面管理后台和搜索引擎优化
- 微服务、Kubernetes 和公开 SaaS 平台化改造
- 支付、配额、运营统计和跨设备同步
- 多智能体辩论、长期记忆、LLM-as-Judge 和评测运营平台
- ChromaDB、pgvector 或另一套向量检索实现

## 七、规模约束

- 前端保持一个主要页面，不增加管理后台。
- 后端保持单个 FastAPI 应用和单进程任务管理。
- 同一时间只运行一个研究任务，其他请求得到明确忙碌提示。
- SQLite 只承担恢复最近任务、执行活动、证据、引用核验和报告元数据的职责。
- 历史任务数量设置上限，不建设检索、标签和统计系统。
- 只有现有主体功能无法支持稳定 Web 闭环时，才允许小范围调整核心代码。

## 八、最终交付物

- 一个命令构建前端并启动 FastAPI 单端口应用
- 可完成生产构建并由后端托管的 React 单页前端
- 无文件与带文件 RAG 两条完整演示流程
- 任务恢复、取消、错误提示和报告下载
- 离线测试、代码检查、中文 README 和架构说明
- 中文演示流程、故障排查和界面截图
- 可复现的 RAG 排名报告和 Agent 执行结构评测报告
