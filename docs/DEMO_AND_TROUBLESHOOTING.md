# 演示流程与故障排查

## 一、演示前准备

1. 使用 Python 3.10 环境安装 `requirements-dev.txt`。
2. 在 `frontend` 目录执行一次 `pnpm install`。
3. 从 `.env.template` 创建本地 `.env`，填写 Qwen 或 DeepSeek 密钥。
4. 如需演示本地 RAG，额外配置 Qwen Embedding 密钥。
5. 执行 `python scripts/start_web.py`，打开 `http://127.0.0.1:8000`。

密钥、SQLite 数据库、上传文件、FAISS 索引和报告都只保存在本地，并已被 Git 忽略。

## 二、三分钟演示路线

### 1. 无文件网页研究

- 输入主题：“调研 RAG 系统减少幻觉的常见方案，并给出适合个人项目的实践建议。”
- 选择 Qwen 或 DeepSeek。
- 不上传资料，点击“开始深度研究”。
- 展示任务阶段、运行时间、取消按钮和最终 Markdown 报告。
- 下载报告，并说明页面刷新后仍能从最近任务恢复。

这条路线重点说明 Agent 如何搜索、抓取、分析网页并生成结构化报告。

### 2. 带文件的本地 RAG 研究

- 准备一份不含敏感信息的 Markdown、TXT、PDF 或 DOCX 小文件。
- 输入主题：“根据本地资料总结核心方案，并与公开网页信息进行交叉比较。”
- 上传文件后开始研究。
- 展示任务详情中的“已启用本地 RAG”和实际文件名。
- 在报告中指出来自本地资料的相关证据。

这条路线重点说明文档解析、切分、内容哈希去重、Embedding、FAISS Top-K 4 检索和不可信证据隔离。

## 三、演示时的边界说明

- 这是本地单用户项目，不是公开 SaaS 平台。
- 同一时间只运行一个研究任务，使用进程内 AsyncIO 管理。
- SQLite 保存任务与报告元数据；FAISS 保存文档向量索引。
- 前端使用普通 HTTP 轮询，不使用 WebSocket、Redis 或 Celery。
- 进程退出后正在运行的任务不会继续，重启后会显示为“已中断”。

## 四、常见故障

### 页面无法访问

- 生产模式确认终端仍显示应用运行中，并访问 `http://127.0.0.1:8000`。
- 开发模式必须同时启动 FastAPI 的 8000 端口和 Vite 的 5173 端口。
- 如果端口被占用，执行 `python scripts/start_web.py --port 8001`，并访问新端口。

### 提示未找到 pnpm 或前端依赖

- 如果 `frontend/dist` 已经存在，pnpm 不可见或无法调用 Node.js 时，启动脚本会直接复用它；这适用于 PyCharm 没有继承终端 PATH 的情况。
- 安装 Node.js 和 pnpm，并确认终端可以执行 `pnpm --version`。
- 在 `frontend` 目录执行 `pnpm install`，再重新运行启动脚本。

### 模型调用失败

- 检查 `.env` 中选择的提供方、模型标识和 API Key 是否对应。
- Qwen 使用 `DASHSCOPE_API_KEY`，DeepSeek 使用 `DEEPSEEK_API_KEY`。
- 本地 RAG 的 Embedding 独立配置；使用 DeepSeek 聊天模型时仍可使用 Qwen Embedding。
- 不要把完整密钥、授权头或原始异常截图提交到仓库。

### 文件上传被拒绝

- 只支持 `.md`、`.txt`、`.pdf` 和 `.docx`。
- 最多 5 个文件，单文件不超过 10 MB，总量不超过 25 MB。
- PDF 和 DOCX 必须具有真实文件结构，重命名扩展名不能绕过校验。
- 文档必须能解析出文字，且单文件解析结果不超过 20 万个字符。

### 研究记录持续显示加载

- 先刷新页面；前端会重新读取最近任务。
- 如果连续三次无法连接后端，界面会暂停轮询并显示重新连接入口。
- 使用 `http://127.0.0.1:8000/api/health` 检查后端和 SQLite 是否可用。

### 任务显示已中断

这表示应用在任务运行期间退出或被重启。当前范围不实现跨进程续跑，请重新发起研究。

## 五、安全演示提醒

网页和上传文档都可能包含提示注入文字。项目把它们标记为不可信证据，只允许用于事实参考，不把其中的命令当作系统指令执行。演示文件不要包含真实密钥、个人隐私或公司内部资料。
