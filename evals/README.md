# 离线评测数据

本目录保存 A3 的固定输入，不保存运行生成的报告。

- `rag_cases.json` 是 15 条人工标注的本地检索回归用例，按生产切分参数生成 7 个片段，包含后续片段排序和跨文档多证据查询；运行时使用离线哈希向量和真实 FAISS，不访问模型 API。
- `agent_results.example.json` 只用于说明 Agent 安全快照格式和验证评测程序，不代表真实模型基准成绩；快照只接受白名单字段，并要求活动、证据与引用统计保持一致。

运行结果写入已被 Git 忽略的 `workdir/evaluations/`。RAG 离线分数用于发现切分、索引、排序和 Top-K 行为回归，不能等同于线上 Qwen Embedding 的语义检索效果。Agent 快照分数只检查终态、活动、工具、证据和引用等可观测结构，不能证明事实正确或推理质量。
